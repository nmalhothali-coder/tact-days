# TACT DAYS — الكود المصدري

منصة تاكت للأيام العالمية. موقع ساكن بالكامل: لا build، لا مكتبات خارجية، لا backend.

```
index.html                  الصفحة (الهيكل فقط)                 ~5KB
assets/styles.css           كل التنسيقات                        ~47KB
assets/data.js              البيانات: 135 مناسبة + 15 تصنيف     ~62KB
assets/app.js               كل المنطق والواجهات                 ~100KB
assets/readex-pro.woff2     خط Readex Pro (Variable, 160–700)   ~118KB
assets/tact-logo.png        لوقو tact
assets/tact-calendar.mp4    فيديو خلفية صفحة التقويم            ~874KB
assets/poster.jpg           صورة الفيديو قبل التشغيل
data/occasions.csv          المصدر: 135 صفاً بكل الحقول
data/categories.csv         الـ15 تصنيفاً
data/review-queue.csv       ما يحتاج مراجعة تحريرية
```

## التشغيل

```bash
python3 -m http.server 8000
```
ثم `http://localhost:8000`

**لا تفتح `index.html` بالنقر المزدوج** — بروتوكول `file://` يمنع تحميل الخط والسكربتات في أغلب المتصفحات. لازم سيرفر، ولو بسيط.

## الرفع

ارفع المجلد كما هو على Netlify أو Vercel أو Cloudflare Pages أو GitHub Pages أو أي FTP. لا متغيرات بيئة ولا إعدادات خادم.

## خريطة `app.js`

الملف مقسّم إلى كتل بالترتيب:

| الكتلة | المحتوى |
|---|---|
| `T` | الترجمات كاملة (عربي + إنجليزي). أي نص في الواجهة موجود هنا، لا شيء مكتوب داخل المكوّنات |
| `g2jd` / `jd2h` / `toHijri` | التحويل الهجري بالخوارزمية الحسابية (التبولار) |
| `resolveDate` | يحسب تاريخ أي مناسبة لسنة معيّنة: هجرية تُحسب من `hm`/`hd`، متغيّرة من `rule` |
| `yearIndex` | يفهرس كل المناسبات لسنة واحدة (مخزّن مؤقتاً) |
| `buildICS` / `downloadICS` | توليد ملف التقويم |
| `FAV` / `renderTray` / `exportPlan` | «خطّتي» — الحفظ في المتصفح والتصدير الجماعي |
| `yearPulse` / `wirePulse` | خريطة نبض السنة (365 مربعاً) |
| `GAME` + `newQuestion` / `answer` | لعبة «تحدّي الأيام» |
| `downloadCard` | توليد بطاقة PNG بمقاس 1080×1350 عبر canvas |
| `viewHome` … `viewAbout` | الصفحات |
| `render` / `ROUTE_CLASS` | الراوتر وحركة الدخول لكل صفحة |
| كتلة الأحداث الأخيرة | كل النقرات عبر تفويض واحد على `document` |

## شكل بيانات المناسبة

```js
{
  s:   "world-cancer-day",   // slug، يُستخدم في الرابط #/day/<slug>
  en:  "World Cancer Day",
  ar:  "اليوم العالمي لمكافحة مرض السرطان",
  m: 2, d: 4,                // الشهر واليوم الميلادي
  ed:  null,                 // آخر يوم للفعاليات متعددة الأيام (سيتي سكيب: m:2 d:1 ed:4)
  cal: "gregorian",          // أو "hijri"
  hm:  null, hd: null,       // الشهر واليوم الهجري (مطلوبان حين cal="hijri")
  rec: "annual_fixed",       // annual_fixed | annual_lunar | annual_variable | month_long
  rule:"",                   // قاعدة التاريخ المتغيّر، مثل "fourth Friday of November"
  cat: "health-wellness",
  de:  "...", da: "...",     // الوصف بالإنجليزي والعربي
  src: "https://...",        // رابط المرجع
  org: "UN",                 // UN | WHO | UNESCO | KSA | secondary | other
  rel: 5,                    // أهمية تسويقية 1–5، تحدد أي مناسبة تتصدّر حين تتزاحم في يوم واحد
  sen: "sensitive",          // standard | sensitive — تغيّر زاوية مولّد الأفكار
  sc:  "global",             // global | local
  co:  "", note: ""
}
```

لإضافة مناسبة: أضف عنصراً إلى `OCC` في `assets/data.js`. الشبكة والتقويم والتصنيفات وخريطة النبض واللعبة والعدّادات كلها تُحدّث تلقائياً.

## قواعد لا تُكسر

**التكرار يحكم ملف التقويم.** `annual_fixed` فقط هي التي تأخذ `RRULE:FREQ=YEARLY`. المناسبات الهجرية والمتغيّرة تُولَّد لها أحداث صريحة لثلاث سنوات بتواريخ محسوبة، لأن قاعدة تكرار سنوية عليها تعطي تواريخ خاطئة.

**`DTEND` حصري.** للأحداث اليومية الكاملة تكون نهاية الحدث اليوم التالي. للفعاليات متعددة الأيام تكون `ed + 1`.

**الحساسية ليست زينة.** 18 مناسبة موسومة `sensitive`، ومولّد الأفكار يقرأ الحقل ويحوّل المخرجات إلى زاوية توعوية ومساهمة بدل الترويج التجاري.

**كل شيء `unverified`.** في `occasions.csv` كل سجل يبدأ غير موثّق. 66 سجلاً مصدره ثانوي (nationaltoday، timeanddate، ويكيبيديا) ويحتاج استبدالاً بالمصدر الرسمي، و14 بلا مصدر.

## تغيير السنة

ثابت `state.year` يبدأ بالسنة الحالية، ومحدّد السنة في صفحة التقويم يغيّره. كل التواريخ تُعاد حسابتها — بما فيها الهجرية والمتغيّرة.

## تنبيه على التواريخ

التحويل الهجري حسابي (التقويم المدني/التبولار) وقد يختلف يوماً عن أم القرى. رمضان والعيدان وعرفة وعاشوراء تقديرية وتُعتمد بالإعلان الرسمي.

وثلاثة تواريخ في الشيت المصدر خالفت التواريخ الدولية المعروفة فلم تُعتمد: اليوم العالمي للسلام (الشيت ١ يناير — المعتمد ٢١ سبتمبر)، حقوق الإنسان (٢١ مارس — المعتمد ١٠ ديسمبر)، يوم الأم (٩ مارس — المعتمد ٢١ مارس). التعارضات مسجّلة في `data/review-queue.csv`.

ومؤتمر الحج والمنتدى السعودي للإعلام لم تُعلن تواريخهما لـ2027 بعد.
